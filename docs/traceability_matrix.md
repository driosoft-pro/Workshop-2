## Chain integrity checks

| Chain property | How it is enforced |
| --- | --- |
| Requirement → rule | `RULES[*].requirement` in `src/validation.py` carries the AR tags shown above |
| Rule → expectation | suite `meta.rule_id` / `meta.severity` (see `docs/gx_design.md` §3) |
| Expectation → evidence | one JSON per run/stage in `docs/evidence/gx/<stage>/` with per-rule results |
| Transformation → requirement | `T1..T11` rationale column in `docs/transformation_integration.md` |
| DW → KPI | `-- ARn` comments in `sql/kpi_queries.sql`; `docs/analytical_requirements.md` §"Expected outputs" |
| KPI → dashboard | `docs/powerbi_dashboard.md` (page/visual per KPI) |
| Policy → evidence | `docs/evidence_register.md` (evidence IDs → artefact → claim) |
